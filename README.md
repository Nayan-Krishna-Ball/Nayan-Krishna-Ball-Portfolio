## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Nayan-Krishna-Ball/Nayan-Krishna-Ball-Portfolio.git
```

```bash
cd Nayan-Krishna-Ball-Portfolio
```

### Install dependencies

```bash
npm install
```

````

### Run locally

```bash
npm run dev
````

Application will be available at:

```txt
http://localhost:5173
```
